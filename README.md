Hidaya PHP Journey - Software Development Training Portfolio

Welcome to the Hidaya PHP Journey repository! This repository showcases a comprehensive collection of daily practical assignments, algorithm challenges, database architectures, and full-stack web applications developed during the Software Development Training Program at Hidaya Institute of Science and Technology (HIST) from April to August.

--------------------------------------------------------------------------------

Program Overview:

Training Institute: Hidaya Institute of Science and Technology (HIST)
Program: Software Development & Web Engineering Training
Duration: April - August
Core Technologies: PHP 8.x, MySQL, JavaScript (ES6+), AJAX, HTML5, CSS3 (Grid & Flexbox), OOP, PHPMailer, FPDF.
Environment: XAMPP Stack (Apache, MySQL, PHP)

--------------------------------------------------------------------------------

Key Technical Skills Mastered:

- PHP Programming & Fundamentals: Syntax, Control Structures, Arrays, Recursion, Custom Functions, Error Handling & Logging.
- Object-Oriented Programming (OOP): Classes, Objects, Inheritance, Encapsulation, Polymorphism, Magic Methods (__construct, __get, __set).
- Database & SQL Mastery: Relational Database Design, DDL/DML Queries, Aggregations, Joins, Normalization, Data Import/Export.
- Authentication & Security: Session Management, Cookie Persistence, Password Hashing, Role-Based Access Control (RBAC).
- Asynchronous Web Development (AJAX): Dynamic Content Loading, Live Search, Real-Time Chat System, Asynchronous Form Submission without Page Reloads.
- Document & Data Processing: FPDF for PDF Generation (Automated CVs, Dynamic Reports), MS Excel Export Writer, CSV File Parsing & Importing.
- Third-Party Libraries & Integrations: PHPMailer for SMTP Email Notifications, Support Ticket Systems, JS Image Sliders, FontAwesome.
- Modern Web Design: Responsive CSS Grid, Flexbox Layouts, Template Integration, AI-Prompted Web Development.

How to Run Locally:

1. Prerequisites:
   Install XAMPP or any Apache + MySQL + PHP server stack.

2. Setup Workspace:
   Clone or copy this repository into your XAMPP htdocs directory:
   C:\xampp\htdocs\Hidaya-PHP-Journey

3. Start Apache & MySQL:
   Open XAMPP Control Panel and start Apache and MySQL.

4. Import Database Scripts:
   Open http://localhost/phpmyadmin in your web browser.
   For modules containing .sql files (e.g. database.sql), create the respective database and import the .sql schema file.

5. Access in Browser:
   Access any module directly via your browser:
   http://localhost/Hidaya-PHP-Journey/[Module-Folder-Name]/[Subfolder-Name]/
